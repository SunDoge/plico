# 国际化

Plico 核心只定义 `Localizer` 接口和短期借用作用域，不依赖 ICU、Fluent 或系统语言。
`plico-i18n` 是可选的应用依赖，提供 Fluent 消息、变量/复数规则、ICU4X 数字和
Gregorian 日期格式。应用显式选择语言，框架不读系统时钟，也不维护全局 locale。

```rust,ignore
use plico::widgets::{column, text};
use plico_i18n::{Catalog, widgets};

// 初始化一次；不要在每次 show 中重新解析。
let chinese = Catalog::new("zh-CN", [widgets::ZH_CN, include_str!("zh-CN.ftl")])?;

cx.localized(&chinese, |cx| {
    let l = cx.localizer();
    column(cx).children(|cx| {
        text(cx, l.text("welcome", "Welcome"));
    });
});
```

`cx.tr("welcome", "Welcome")` 是相同的无参数查找快捷方式。先取文案，再传给
以 `cx` 为首参的构造函数，或像上例预先取出独立的 localizer 借用。
无参数 Fluent 文案通常直接借用解析后的资源，不创建新的字符串；有变量的格式化
返回临时字符串。资源和 ICU formatter 在 `Catalog` 初始化时创建。

普通 children、component/keyed scope、modal/popover portal 继承 localizer。
嵌套 `localized` 可以覆盖局部语言，返回或 panic 后外层不受影响；框架不保留 catalog
引用。语言变化由应用状态触发下一次 immediate 声明。

## 消息与错误

应用资源使用 Fluent `.ftl`，例如：

```ftl
welcome = 你好，{ $name }！
items = { $count ->
    [one] One item
   *[other] { $count } items
    }
```

使用 `Catalog::format` 和 `FluentArgs` 传入变量；保留 Fluent 默认的双向文本隔离。
`with_fallback(Arc<Catalog>)` 设置消息回退目录；找不到的控件消息使用构造时的英文
fallback。资源语法错误、重复 ID、缺失 ICU 数据在初始化时返回错误；带参数的格式化
错误直接返回。控件无参数消息的运行时错误记录在有界诊断中，可通过 `take_errors()`
取走，避免页面无声失效。

`Catalog::number` 接受整数或 `plico_i18n::Decimal`，不强制把整数转换为 f64。
`Catalog::date` 接受已验证的 `CalendarDate`，不涉及时间戳和隐式时区转换。

## 控件

- `nav_menu` 以 `Route::id()` 查消息，`Route::label()` 是 fallback；导航 key 仍是稳定 ID。
- 日历使用 localizer 的月份/年份与星期格式；周起始日仍由 `WeekStart` 显式选择。
- 日历导航、对话框关闭、搜索选择框的标签、占位与空结果文案可本地化。
- 应用显式加入 `plico_i18n::widgets::EN` / `ZH_CN`，也可以提供同名 key 的自有资源。
  不同时加载默认资源和重名覆盖资源；Fluent 会拒绝重复消息。
- 换语言改变的是文字与布局，不改变控件 ID、路由和 local state。

## 数据裁剪

默认 `embedded-data` 仅包含英文、简体中文和当前 formatter 需要的 ICU4X markers，
约 36 KB。没有启用 ICU4X 的全语言 `compiled_data`。
可禁用默认 feature，通过 `Catalog::with_data` 加载应用自有的静态 blob；生成方法和
Unicode 许可见 `crates/plico-i18n/data/README.md`。普通构建不依赖 datagen。
Fluent 翻译文件由应用 `include_str!` 明确选择，不携带其它应用或语言的消息。

## Gallery 验证

启动 `cargo run -p gallery`，侧栏底部切换 English / 中文；“国际化”页演示变量、
复数、数字、日期和独立的英文 scope。框架导航、常用控件及示例标题提供两种语言；
项目名、用户输入、Markdown 示例正文、布局 API 标签等示例内容保持原样。
支持预览场景中的 `"language": "zh-CN"`，旧场景不写语言时默认为英文。
当前未提供自动 RTL 布局、翻译抽取或系统语言选择；这些不是已有能力。
